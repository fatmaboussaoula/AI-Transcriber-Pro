# AI-Transcriber-Pro

A lightweight multilingual audio transcription, summarization and TTS system for academic use.

---

## 📌 Project Overview

AI-Transcriber-Pro is an intelligent application designed to transcribe audio files into text and generate concise summaries using Natural Language Processing techniques.

The system integrates speech recognition, summarization, and an interactive interface for real-time usage.

---

## 🛠 Technologies Used

- Python  
- OpenAI Whisper (Speech Recognition)  
- Hugging Face Transformers  
- T5-small (Text Summarization)  
- Streamlit  
- PyTorch  

---

## ⚙️ Features

- 🎧 Upload audio files  
- 📝 Automatic speech transcription  
- 📄 AI-based summarization  
- 🌐 Interactive Streamlit web interface  
- 🔊 Text-to-Speech support
